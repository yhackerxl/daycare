# Little Sprouts Daycare Portal

Modern, responsive daycare information portal (Next.js + TypeScript + Tailwind + Lucide).

## Run locally

```bash
npm install
npm run dev
```

## Build (static export for Netlify)

```bash
npm run build
```

Output goes to `out/`.

## Deploy to Netlify

- Build command: `npm run build`
- Publish directory: `out`
